# Introduction
`@hiZollo/games` is a package that provides interfaces of various games. 

# Features
- **Various games** - 2048, tic-tac-toe, bulls and cows, and more game included in this package.
- **Single player mode** - built-in AI algorithms come to the rescue when there's no one to play with in 3 a.m. morning.

# Requirements
- node.js version >= 24

# Installation
```
npm install @hizollo/games
```
